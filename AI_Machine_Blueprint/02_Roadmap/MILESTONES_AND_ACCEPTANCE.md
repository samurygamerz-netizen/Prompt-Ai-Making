# Milestones and acceptance criteria

| ID | Milestone | Acceptance criteria |
|---|---|---|
| M0 | Requirements | Budget, host specs, devices and privacy rules documented |
| M1 | Text prototype | Text request reaches orchestrator and returns useful response |
| M2 | Read-only tools | CPU/RAM/disk values match OS sources |
| M3 | Tool broker | Unknown tool and invalid arguments rejected |
| M4 | Voice | Transcript preview, TTS and cancellation work |
| M5 | Host automation | Allowlist and filesystem sandbox enforced |
| M6 | Model routing | Timeout/fallback and privacy rules tested |
| M7 | Memory | User can inspect, edit, export and delete memory |
| M8 | Device gateway | Only enrolled devices accepted; revocation works |
| M9 | Custom OS | Boots, updates and rolls back on test hardware |
| M10 | Release candidate | Critical tests pass; restore from backup demonstrated |

Definition of done: requirements, error cases, permissions, timeout/cancel, verified outcome, secret-free logs and automated tests.
